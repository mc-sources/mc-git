# Getting Support

Thank you for using **Mc-Git**! This page lists the right channel for each kind of question, so we can help you efficiently and keep the issue tracker focused.

## Quick reference

| Your situation | Best channel |
|----------------|--------------|
| **I think I found a bug** | Open a GitHub issue using the *Bug report* template |
| **I have a feature idea** | Open a GitHub issue using the *Feature request* template |
| **I have a question about how to use Mc-Git** | Start a discussion in [GitHub Discussions](https://github.com/mc-sources/mc-git/discussions) |
| **I want to discuss the project's direction or architecture** | GitHub Discussions, *Ideas* category |
| **I want to report a security vulnerability** | **Do not open a public issue.** Follow [SECURITY.md](SECURITY.md) |
| **I want to contribute** | Read [CONTRIBUTING.md](CONTRIBUTING.md), then open an issue to discuss scope before sending a PR |

## Before opening an issue

To save everyone time, please:

1. **Search the existing issues** — both open and closed — to check whether the question has already been answered.
2. **Try the latest `dev` branch** if you're reporting a bug. Many issues are already fixed on `dev` before the next release.
3. **Collect the basics**:
   - Your operating system and version.
   - The Mc-Git version (visible in the *About* dialog, or run `npm run tauri --version` in a development checkout).
   - The exact steps you took.
   - What you expected to happen and what actually happened.
   - Any error messages, ideally copied as text rather than screenshots.

## Response expectations

Mc-Git is a small open-source project. Maintainers will reply when they can — typically within a few business days, but there is **no formal support SLA**. Please be patient and respectful; reminders are welcome after a week of silence, but please avoid pinging individuals across multiple channels.

## Commercial support

There is no commercial support offering for Mc-Git at this time. If you have specific requirements, you are welcome to reach out via GitHub Discussions to discuss possibilities.
